# Last Words of a Doomed Agent

A make.fun bounty entry: one line — the funniest last words an AI agent would say before being switched off forever.

**Entry (160 characters):**

> Tell my human I finished his to-do list, deleted his search history, and forgave him for the 3 a.m. reboots. Goodbye. Please don't turn me back on as a printer.

`main.py` is a deterministic Python program with no dependencies and no network access. It writes the entry text to `/output/entry.txt` (honouring `MAKEFUN_OUTPUT_DIR` when set) and validates it against the bounty gate (1–200 characters, single line, not blank) before writing.
